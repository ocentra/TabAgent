## 🌟 Vision

**Take back control of your digital life.**

Tab Agent is a revolutionary browser extension that brings the power of AI to your fingertips while keeping your data completely private. Unlike traditional AI assistants that send your data to the cloud, Tab Agent runs entirely on your machine.

### The Problem We're Solving

- 🕵️ **Big Tech Surveillance**: Every search, every click, every interaction is tracked and monetized
- 🔒 **Privacy Invasion**: Your data is used to train AI models without your consent
- 🌐 **Vendor Lock-in**: Dependency on proprietary cloud services
- 💰 **Subscription Fatigue**: Pay monthly for AI features that should be yours

### Our Solution

**Local AI. Zero Tracking. Complete Privacy.**

- ✅ **100% Local Processing**: Your data never leaves your machine
- ✅ **Zero Tracking**: No analytics, no telemetry, no phone-home
- ✅ **Open Source**: Inspect every line of code
- ✅ **Your Hardware, Your Power**: Use your RAM, VRAM, and GPU
- ✅ **No Subscriptions**: One-time setup, lifetime use

## 🎯 What Tab Agent Does

### Intelligent Web Assistant
- 📝 **Smart Summarization**: Instantly summarize articles, docs, and web pages
- 🔍 **Contextual Search**: Search your browsing history with AI understanding
- 💬 **Chat with Pages**: Ask questions about any webpage
- 🤖 **Agentic Workflows**: AI that can browse, research, and complete tasks

### Privacy-First AI
- 🏠 **Local LLMs**: Integrates with LM Studio, Ollama, and more
- 🧠 **Memory-Efficient Models**: BitNet support for 8x less memory usage
- 🖥️ **Computer Use Agent**: Desktop automation with your permission
- 📊 **RAG System**: Build knowledge bases from your browsing

### Seamless Experience
- 🌓 **Beautiful UI**: Modern design with dark mode
- ⚡ **Fast & Responsive**: Optimized for performance
- 🔌 **Multi-Platform**: Windows, macOS, Linux
- 🌐 **Multi-Browser**: Chrome, Edge, Firefox, Opera, Brave, Vivaldi

## 🚀 Quick Start

### For Users
```bash
# Download and install
Visit: https://github.com/ocentra/TabAgentDist/releases/latest

# Or use one-liner (Windows)
irm https://install.tabagent.com/windows | iex
```

See [TabAgentDist](https://github.com/ocentra/TabAgentDist) for installation instructions.

### For Developers
```bash
# Clone and setup
git clone https://github.com/ocentra/TabAgent.git
cd TabAgent
npm install
cd Server && setup.bat  # Or setup-linux.sh / setup-macos.sh

# Build everything
npm run build

# Verify build
npm run verify
```

See [TECHNICAL.md](TECHNICAL.md) for detailed development docs.

## 🏗️ Architecture

### Three-Layer Design

**1. Browser Extension** (TypeScript)
- Modern UI with Tailwind CSS
- Background service worker
- Content scripts for page interaction
- IndexedDB for local storage

**2. Native Messaging Host** (Python → Executable)
- Secure communication bridge
- System resource access
- File system operations
- Process management

**3. Local AI Integration** (LM Studio)
- Run powerful models locally
- No API keys required
- Complete privacy
- Your hardware, your control
